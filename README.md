# 🩺 AarogyaAI - Rural Health AI Platform

AI-powered healthcare solution for rural India, tackling doctor shortage through multilingual symptom analysis, visual diagnostics, and micro-clinic franchise model.

## Features
- 🤖 AI Symptom Checker (5 languages)
- 📸 Anemia Detection (Computer Vision)
- 📊 Impact Dashboard
- 💰 Complete Business Model

## Tech Stack
- Streamlit (Frontend)
- Groq AI (LLM)
- OpenCV (Diagnostics)
- Python

## Setup
1. Clone repository
2. Install: `pip install -r requirements.txt`
3. Create `.env` file with `GROQ_API_KEY=your_key`
4. Run: `streamlit run app.py`
